# 🎬 Movie Recommender

C++로 구현한 영화 추천 시스템입니다.  
사용자 평점 데이터를 기반으로 유사한 취향의 사용자를 찾아 영화를 추천합니다.

---

## 빌드 방법

```bash
# 데이터 파일 생성
make makecsv
./makecsv

# 빌드
make

# 실행
make run
```


---

## 실행 방법

```bash
./recommend
```

실행하면 아래 메뉴가 표시됩니다:

```
[ 영화 추천 시스템 ]
1. 영화 추가       2. 영화 검색
3. 전체 영화 목록  4. 평점순 정렬
5. 사용자 추가     6. 전체 사용자 목록
7. 평점 입력       8. 영화별 평점 보기
9. 영화 추천 받기  10. 통계 보기
0. 종료
```

---

## 주요 기능

### 영화 관리
| 메뉴 | 기능 |
|------|------|
| 1. 영화 추가 | ID, 제목, 장르, 개봉연도 입력으로 영화 등록 |
| 2. 영화 검색 | 제목 또는 장르로 검색 (대소문자 무시) |
| 3. 전체 영화 목록 | 등록된 모든 영화 출력 |
| 4. 평점순 정렬 | 평균 평점 높은 순으로 정렬 출력 |

### 사용자 관리
| 메뉴 | 기능 |
|------|------|
| 5. 사용자 추가 | ID, 이름, 이메일 입력으로 사용자 등록 |
| 6. 전체 사용자 목록 | 등록된 사용자 및 평점 수 출력 |

### 평점
| 메뉴 | 기능 |
|------|------|
| 7. 평점 입력 | 사용자 ID, 영화 ID, 점수(0.0~5.0) 입력 |
| 8. 영화별 평점 보기 | 특정 영화의 평점 목록 및 평균 출력 |

### 추천
| 메뉴 | 기능 |
|------|------|
| 9. 영화 추천 받기 | 유사도 기반 협업 필터링으로 영화 3편 추천 |

> 공통 평점 영화 수와 점수 차이를 계산해 유사한 사용자 Top 2를 찾고, 내가 보지 않은 영화 중 점수가 높은 것을 추천합니다.

### 통계 (확장 기능)
| 항목 | 내용 |
|------|------|
| 1. 전체 현황 | 총 평점 수, 전체 평균 평점 |
| 2. 장르별 현황 | 장르별 영화 수 및 평균 평점 (많은 순) |
| 3. 유저별 평점 수 랭킹 | 가장 활발한 사용자 순위 |
| 4. 평점 높은 영화 Top 5 | 평균 평점 기준 상위 5편 |

## 클래스 구조

```
BaseManager (추상 클래스)
├── MovieManager   — 영화 데이터 관리, 검색/정렬
├── UserManager    — 사용자 데이터 관리
└── RatingManager  — 평점 데이터 관리

Movie              — 영화 데이터 클래스 (연산자 오버로딩)
User               — 사용자 데이터 클래스
Rating             — 평점 데이터 클래스

SimilarityCalculator — 사용자 간 유사도 계산 (정적 클래스)
Recommender          — 협업 필터링 추천 알고리즘
Statistics           — 통계 기능 (확장)
MovieConstants       — 전역 상수 정의 (namespace)
```

## 데이터 파일

| 파일 | 형식 | 설명 |
|------|------|------|
| `data/movies.csv` | id, title, genre, year, rating | 영화 목록 |
| `data/users.csv` | id, name, age | 사용자 목록 |
| `data/ratings.csv` | userId, movieId, score | 평점 데이터 |

프로그램 종료 시 변경 내용이 자동 저장됩니다.
